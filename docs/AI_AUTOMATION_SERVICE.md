# AI Automation Service

I build practical AI automation systems that connect real Windows applications, browser workflows, APIs, and Python tools.

## Current capabilities

- Windows UI Automation with Python
- Direct mouse/keyboard fallback through a localhost-controlled input layer
- Browser workflow automation
- REST/API integration
- AI-agent state machines and verification
- Logging, testing, and failure recovery
- Data processing and document workflows
