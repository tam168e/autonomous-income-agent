# Autonomous Income Agent

Android/Kotlin + Jetpack Compose project with a modular income-provider architecture and a FastAPI backend scaffold.

## Google AI Studio
Import this repository from **Build Mode → Add files (+) → Import from GitHub**.

The repository root is intentionally the Android Gradle project root (`settings.gradle.kts`, `app/`, etc.).

## Important
This repository contains no fake earnings and no provider credentials. Real providers must be added only when their current terms permit the required automation and payment path is verifiable.
